What you get

  • 3D preview — orbit around the finished walk-in and see how the columns sit together.
  • Plan and elevations — a dimensioned plan from above plus one elevation per wall, every shelf bay measured.
  • Cut list — every panel, shelf, divider, drawer front and rod, grouped by size and tagged to match the drawings.
  • PDF — drawings and cut list in one document, ready to print or send to a shop.
  • Templates — start from a ready layout instead of an empty room.
  • Share link — pass a design to someone else as a URL; nothing is stored on a server.

What it is not

No doors on units, no drawer boxes or hardware, rectangular rooms only. It plans an open walk-in: carcasses, shelves, dividers, drawer fronts and hanging rods. If you need hinged fronts, runner specs or a room with an odd footprint, this is the wrong tool.

Guides

The practical dimensions the planner is built on, written out in full.

  • Walk-in wardrobe dimensions — depth, width, plinth, ceiling gap and board thickness.
  • Hanging rail height — single and double hanging, and the 2000 mm reach limit.
  • Shelf depth and spacing — pitch for folded clothes and shoes, and how far a shelf can span.
  • Walk-in closet minimum width — the smallest room that still works, by layout.

FAQ

Is it free?

Yes. Walk-in Planner is free and open source under the MIT licence. There is no account, no sign-up and no paid tier.

Do I need to install anything?

No. It runs in any modern desktop or mobile browser. There is nothing to download and no plugin to install.

Where is my project stored?

In your browser's localStorage, on the device you are working on. Nothing is uploaded to a server. Export the project as a JSON file to back it up or move it to another machine, and import that file to carry on.

What does the cut list include?

Every carcass panel — sides, top, bottom, back and plinth — plus shelves, dividers, drawer fronts and hanging rods, with sizes and quantities, tagged (B1, R2, L1) to match the drawings. Drawer boxes, runners and other hardware are not included.

Can I work in inches?

Yes. A units toggle switches the whole interface, drawings and cut list between millimetres and inches. The model itself stays in millimetres, so numbers never drift as you switch back and forth.

What can I export?

A PDF containing the dimensioned plan, one elevation per wall and the cut list — enough to take to a panel shop — and the project itself as a JSON file you can re-import later.
