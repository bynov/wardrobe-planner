# Walk-in Planner Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-skin and re-structure the app UI and the landing/guide pages to the Claude Design handoff (option 2a "modes" layout, light + dark themes) without touching the model, geometry, drawing, PDF or persistence logic.

**Architecture:** A UI-layer change. One token sheet (`site/tokens.css`) feeds both the static site and the React app; a `data-theme` attribute on `<html>` plus a `prefers-color-scheme` fallback switch themes, set before first paint by an inline script. The zustand store grows three UI fields (`theme`, `insertAt`, `sheetOpen`) and a fourth tab (`setup` = Room mode). The design tab becomes "wall tabs + canvas + preset tray + inspector"; room settings move into Room mode; the spawn popup menu becomes an insert slot + a persistent preset tray. The SVG renderer emits token colours instead of hex so drawings follow the theme.

**Tech Stack:** React 18 + TypeScript + Vite 8, zustand 5, vitest (node env, DOM-free tests), plain CSS with custom properties (oklch), Google Fonts (Schibsted Grotesk, IBM Plex Mono).

**Spec:** `docs/superpowers/specs/2026-10-09-redesign-handoff/README.md` (the binding brief) with interactive prototypes in `docs/superpowers/specs/2026-10-09-redesign-handoff/designs/*.dc.html` (`Overview.dc.html` 2a/2b is canonical for Design mode; open the HTML files in a browser from that folder, or read their `<style>` and markup directly for exact values).

## Review Focus

1. **Theme override vs OS theme.** A user on a dark OS who picks "Light" must get light immediately, after reload, and on the landing as well as the app, with no flash. Pinned in Task 1 (`applyTheme` + inline script test).
2. **Insert slot staleness.** `ui.insertAt` must be dropped when the wall changes, when the wall is disabled, when the column list of that segment changes length (undo, remove), or when the project is switched; otherwise a preset lands in the wrong place or at an out-of-range index. Pinned in Task 4 (store test).
3. **Typing into the width stepper.** The stepper's value box must still accept typed values and inch fractions (`23 5/8`) through `useNumberInput`; ±50 mm clicks must clamp at the segment's free length rather than overflow. Pinned in Task 5.
4. **Room mode on an existing project.** Picking a template in Room mode while the current project has edits (`past.length > 0` or more than one column) must ask for confirmation and create a *new* project, never overwrite in place. Pinned in Task 6 (store test for `applyTemplate`).
5. **Mobile sheet and keyboard.** With the bottom sheet collapsed, a tap on a unit selects it and keeps the sheet collapsed (shows the summary); `Delete`/`Backspace` inside a sheet input must not remove the unit (`isTyping` guard already exists; verify it covers the stepper inputs). Pinned in Task 8.
